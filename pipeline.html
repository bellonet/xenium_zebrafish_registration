1
Crop & Tag 2D Slices
1_crop_and_tag_2d_slices.py
▾ details
Detects and crops individual fish from each slide, assigns consistent IDs across tiles and runs, and orders slices by Z-position into a unified stack per fish.

Inputs

  • morphology_focus OME-TIFF (3 runs)
  • cells.parquet (cell centroids, for clustering)

Outputs

  • individual_fish_2d/{fish}/c{ch}/{gnum}_{run}_{tile}.tif
  • zfish_bboxs_tagged_final.csv
  • tile_rotation.csv
  • fish_bbox_summary_tagged_*.csv
  • QC PNGs (tiles, bboxes, rescues)

Steps (resumable with --from-step)

tiles bboxes crop tag rescue save_dapi unify

Key parameters & manual choices

  • IGNORE_TILES — manually skip bad tiles per run
  • DELETE_SLICES — manually remove known-bad slices per fish
  • Fish size filter: 22–250 µm; ≥15 cells/fish required
  • ID tagging: rotation sweep −25° to +25° (step 5°) to find best 2-row layout
  • Run ordering by NCC — automatic, but result should be inspected

2
Rigid 2D Registration (within fish)
2_rigid_registration.py
▾ details
Aligns all 2D slices per fish into a common canvas using DV rotation + elastix rigid registration, then assembles 3D stacks including segmentation and per-gene transcript density.

Inputs

  • individual_fish_2d/{fish}/c{ch}/*.tif
  • fish_bbox_summary_tagged_*.csv
  • transcripts.parquet (per run, for DV rotation + per-gene)
  • cells.parquet, cells.zarr (segmentation)
  • leiden10annots.csv (cell type labels)

Outputs

  • 2_registered/{fish}/rigid_3d_c{ch}.tif (3D stacks)
  • transforms/{gnum}.txt (elastix params per slice)
  • transforms.json (DV angles, canvas size, crop box)
  • seg_cells_3d.tif, seg_nuclei_3d.tif
  • tissue_map_3d.tif, cell_type_label_3d.tif
  • per_gene/{gene}.tif (top-40 SVGs + markers)

Steps (selectable with --steps)

register segmentation stack per_gene

Key parameters

  • Propagation outward from middle slice (minimises drift accumulation)
  • DV rotation: dorsal genes (pax6b, scrt2, sox3…) vs ventral (etv2, foxa3…); ≥5 transcripts each, min 1° applied
  • Elastix: Mutual Information, 3 resolutions, 256 iter, 6000 samples, 8 threads
  • Per-gene: top-40 spatially variable + structural markers, σ=10 µm Gaussian blur
  • RUN_FOLDERS dict must match Script 1 run names

Registration Experiments (2nd-pass correction)
3_registration_experiments.py
▾ details
Runs a correction pass on script 2's result using 4 alternative driving images (cell-type maps, gene composites, blends) and evaluates each quantitatively.

Inputs

  • 2_registered/{fish}/c0/*.tif (DAPI registered)
  • 2_registered/{fish}/tissue_map/*.tif
  • transcripts.parquet (gene composites)
  • transforms.json (canvas / DV info)

Outputs per experiment × fish

  • 3_improved_registration/{exp}/{fish}/c0_3d.tif
  • correction_transforms.json (δ angle, tx, ty per slice)
  • evaluation_fish{N}.csv (NCC, smoothness, sharpness)

Steps

register evaluate

4 experiments tested

  • tissue_mask — grayscale cell-type label map
  • gene_composite — tp63 + myod1 + tbxta + sox3 density (σ=3 µm)
  • dapi_blend — 0.5×DAPI + 0.5×cell-type map
  • multi_metric — 0.6×cell-type + 0.4×gene composite
  • Metric: NCC (AdvancedNormalizedCorrelation), 200 iter
  • Evaluation: ncc_dapi, ncc_tissue, smooth_px, smooth_deg, Z-sharpness

4
Cross-Fish 3D Registration
4_cross_fish_registration.py
▾ details
Registers all 6 fish volumes to a single reference fish in 3D, testing 4 strategy combinations and evaluating WT and mutant groups separately.

Inputs

  • 3_improved/{best_exp}/{fish}/c0_3d.tif (corrected DAPI)
  • 2_registered/{fish}/rigid_3d_c{1,2,3}.tif (fluorescence)
  • tissue_map_3d.tif (for dapi_blend driving)
  • seg_cells_3d.tif, seg_nuclei_3d.tif, cell_type_label_3d.tif

Outputs per experiment × fish

  • 4_registered/{exp}/{fish}/c{ch}.tif (3D float32)
  • seg_cells.tif, seg_nuclei.tif, cell_type_label.tif
  • transform.json (full 3D transform parameters)
  • evaluation.csv, evaluation_per_fish.csv

Steps

register evaluate

4 experiment combinations (2 driving × 2 stages × 1 Z-spacing)

  • Driving: dapi | dapi_blend (cell_type_map excluded after evaluation)
  • Stages: rigid | rigid_affine (affine corrects scaling/shear)
  • Z-spacing: 10 µm confirmed; XY at full resolution (DOWNSAMPLE_XY=1)
  • Elastix rigid: 4 resolutions, 500 iter; affine: 3 resolutions, 300 iter
  • Reference fish: default=1 (set with --reference flag)
  • Eval: NCC + Dice vs reference, grouped WT (fish 4,5,6) vs Mutant (1,2,3)

5
Trim Yolk Sac
5_trim_yolk.py
▾ details
Removes the yolk sac region using a per-group consensus mask (WT and mutant separately), preserving real biological differences while excluding noisy posterior slices.

Inputs

  • 4_registered/{best_exp}/{fish}/cell_type_label.tif — all 6 fish

Outputs

  • 5_consensus/consensus_mask.tif — (Z_trim, H, W) binary keep mask
  • cutoff_info.json
  • qc_agreement_curve.png ← validate this!
  • 5_consensus/{fish}/cell_type_label.tif — masked & Z-trimmed

Key parameters (tunable with CLI flags)

  • EXPERIMENT — must be hard-coded to the Script 4 choice
  • MIN_AGREEMENT=2/3 — ≥2 of 3 fish per group must agree on tissue presence
  • Z_AGREEMENT_THRESHOLD=0.5 — Z-slices below this mean agreement excluded
  • Groups: WT = fish 4,5,6 · Mutant = fish 1,2,3
  • Run automatically by Snakemake after script 4
  • Always inspect qc_agreement_curve.png to validate Z cutoff

6
Apply Full Registration Stack
6_apply_registration.py
▾ details
Projects transcripts, cell centroids, or custom images into the final registered space, composing all transform layers into a single resampling step to minimise interpolation error.

Inputs

  • transforms.json (Script 2 — layer 1 per-slice rigid)
  • correction_transforms.json (Script 3 — layer 2 correction)
  • transform.json (Script 4 — layer 3, 3D affine/rigid)
  • transcripts.parquet and/or cells.parquet
  • Optional: custom (Z, H, W) TIFF

Outputs

  • 6_applied/transcripts_registered_fish{N}.parquet
  • 6_applied/cells_registered_fish{N}.parquet
  • (new columns: x_reg_px, y_reg_px, x_reg_ds, y_reg_ds, z_reg)
  • 6_applied/{name}_registered_fish{N}.tif (if image provided)

Configuration (edit top of file before running)

  • FISH, RUN — which fish and which Xenium run to process
  • SCRIPT3_EXP — chosen Script 3 experiment name
  • SCRIPT4_EXP — chosen Script 4 experiment name
  • REFERENCE_FISH=1 — must match Script 4 reference
  • APPLY_TO_TRANSCRIPTS / APPLY_TO_CELLS / APPLY_TO_IMAGE — toggle what to run
  • NN_INTERPOLATION=False — set True for label/segmentation images
